# صور المنتجات

لا تضع صور الكاميرا الأصلية الكبيرة مباشرة في الموقع. قبل الرفع، جهّز لكل منتج نسخة مربعة بحجم **640×640 بكسل** بصيغة **WebP** (أو AVIF عند توفره) وبحجم لا يزيد عادة عن **120 كيلوبايت**.

1. أنشئ مجلدًا باسم `images/products`.
2. ضع صورة كل منتج فيه، مثل: `images/products/ghriba-hazelnut.webp`.
3. في `script.js`، حدّث حقل `image` للمنتج نفسه إلى `products/ghriba-hazelnut.webp`.

مثال:

```js
{ name: 'غريبة بندق', price: 40, image: 'products/ghriba-hazelnut.webp' }
```

الموقع يعرض 12 بطاقة فقط في البداية، ثم يحضّر الصور عند الطلب باستخدام `loading="lazy"` و`decoding="async"`. بهذه الطريقة لا تُحمّل صور المنتجات غير الظاهرة للزائر.

استخدم نفس زاوية التصوير، خلفية هادئة، وإضاءة متقاربة لكل المنتجات؛ الاتساق البصري أهم من استخدام صور عالية الدقة.
